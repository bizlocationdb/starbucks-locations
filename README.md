# Starbucks Locations Dataset

This repository contains Starbucks store location data from multiple countries in CSV format. The lists were updated in April 2026.

## Fields

The repository includes country-specific CSV files containing Starbucks location data, which may include:

- Store ID
- Store Name
- Ownership Type
- Country
- City
- Region
- ZIP Code
- Address
- Coordinates
- Phone Number
- Opening Hours
